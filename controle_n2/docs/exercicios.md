# Exercícios do Controle N2

As atividades abaixo usam dados fictícios e podem ser feitas durante a preparação do projeto.

## 1. Ler uma tabela de alunos

Escolha três linhas do [arquivo de exemplo](alunos.exemplo.md). Modele um tipo `AlunoExemplo` em TypeScript e digite os dados em uma lista. Guarde a matrícula como `string`. Teste com uma matrícula inventada que começa com zero e verifique se ela permanece intacta.

## 2. Criar uma lista com busca

Mostre os três nomes em um componente React e use a matrícula como `key`. Acrescente uma busca por nome e uma mensagem para a busca sem resultados. Verifique se apagar o texto mostra os três nomes novamente.

## 3. Escrever casos a partir da especificação

Com a lista fictícia, escolha um grupo e depois troque para outro. Confira a contagem de vagas antes e depois. Reinicie o servidor, entre novamente e confira se o último grupo continua selecionado. Compare o resultado com as rotas descritas na [referência da API](api.md).
