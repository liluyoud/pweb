# Documentação do Controle N2

O Controle N2 acompanha os grupos que farão a atividade da nota N2. O professor consulta grupos, repositórios e o histórico de auditoria no painel. Os enunciados dos 10 trabalhos estão disponíveis abaixo.

| Documento | Conteúdo |
| --- | --- |
| [Trabalhos da N2](trabalhos.md) | Enunciados dos 10 projetos em grupos de até 10 integrantes |
| [Critérios de avaliação](criterios-de-avaliacao.md) | Rubrica dos 50 pontos e procedimento das perguntas individuais |
| [API](api.md) | Catálogo público, sessões, APP_KEY e documentação Scalar |
| [Banco de dados](banco-de-dados.md) | Armazenamento das escolhas e controle de vagas |
| [Exercícios](exercicios.md) | Atividades de preparação para a implementação |
| [Alunos fictícios](alunos.exemplo.md) | Dados de exemplo para os exercícios |

O arquivo local `alunos.md` contém os dados reais e está coberto pelo [`.gitignore` da raiz](../../.gitignore). Use `alunos.exemplo.md` nos exemplos, nas capturas de tela e nos arquivos que serão versionados.

Consulte também o [material de estudo compartilhado](../../docs/README.md).
